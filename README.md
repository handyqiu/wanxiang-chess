# 万象棋境 · 王者万象棋教学攻略平台

> 静态单页应用（Vue 3 + Tailwind CSS CDN），可直接部署到任何静态托管平台。

## 本地预览

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：本地服务器（推荐）
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 部署

拖拽此目录到 https://app.netlify.com/drop 即可自动生成公网网址。

## 内容

- 新手入门（核心机制、运营节奏、关键词条）
- 六大阵营体系
- 棋手强度梯队（18 位）
- 阵容码库（21 套，一键复制导入）
- 精选教学视频（12 个）
- 全局搜索 + 导入校验
